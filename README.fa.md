# Radio Ainur
 
### یک آرشیو منتخب موسیقی برای کشف، تجربه و به‌یادآوردن
 
Radio Ainur یک پروژه مستقل برای **کیوریشن و آرشیو موسیقی** است؛ مجموعه‌ای از قطعاتی که برای کشف، شنیدن دوباره و ثبت در یک آرشیو ماندگار انتخاب شده‌اند.
 
این پروژه تلاش می‌کند موسیقی را صرفاً به‌عنوان مجموعه‌ای از فایل‌ها یا لینک‌ها نگاه نکند؛ بلکه آن را به‌عنوان مجموعه‌ای از تجربه‌ها، خاطره‌ها و مسیرهای کشف حفظ کند.
