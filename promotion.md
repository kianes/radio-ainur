# Radio Ainur — Promotion & Discovery
 
## Overview
 
Radio Ainur uses a cross-platform discovery model in which each platform serves a different function within the wider project.
 `GitHub Documentation + Structured Archive         ↓ GitHub Pages Music Discovery Interface         ↓ Telegram Publishing + Original Archive         ↓ Spotify Listening + Playlist Discovery ` 
The objective is not to duplicate the same content across platforms, but to create complementary paths into the Radio Ainur archive.
  
## Discovery Model
 
Radio Ainur can be discovered through three primary entry points:
 
### GitHub
 
GitHub introduces the project as a structured music archive and content curation project.
 
Its role is to communicate:
 
 
- What Radio Ainur is
 
- How the archive is structured
 
- How the collection is curated
 
- How the content system works
 
- How the archive can be explored
 

 
GitHub is therefore the primary documentation and portfolio layer.
  
### Telegram
 
Telegram is the primary publishing and original archive layer.
 
It provides access to individual published tracks and preserves the chronological history of Radio Ainur.
 
The GitHub music index connects individual tracks back to their original Telegram posts.
  
### Spotify
 
Spotify provides a listening-oriented entry point.
 
Its primary purpose is music consumption and playlist discovery rather than documentation.
  
## Cross-Platform Discovery
 
Each platform should direct interested listeners toward the other relevant layers.
 `                     RADIO AINUR                           │              ┌────────────┼────────────┐              ↓            ↓            ↓           GitHub       Telegram      Spotify              │            │            │              └────────────┼────────────┘                           ↓                    Music Discovery ` 
The platforms should remain connected without becoming repetitive.
  
## GitHub Discovery
 
The GitHub repository should make the project understandable immediately.
 
Key discovery elements include:
 
 
- Clear repository description
 
- Relevant repository topics
 
- Strong README
 
- Complete music index
 
- Structured documentation
 
- Consistent naming
 
- Searchable metadata
 
- GitHub Pages
 
- Versioned releases
 

 
The repository should communicate both the creative and organizational aspects of Radio Ainur.
  
## Telegram Discovery
 
Telegram is where the archive is experienced at the individual-track level.
 
Discovery can occur through:
 
 
- Individual posts
 
- Channel browsing
 
- Shared posts
 
- Search
 
- External links
 
- References from the GitHub archive
 
- References from Spotify or other project surfaces
 

 
The original Telegram post should remain the canonical publishing reference for each archived track.
  
## Spotify Discovery
 
Spotify functions primarily as a listening environment.
 
The playlist provides a low-friction way for listeners to experience the collection without navigating the documentation layer.
 
Spotify therefore complements rather than replaces the GitHub and Telegram archive.

## Discovery Paths
 
A user may enter the Radio Ainur ecosystem from different directions.
 
### Path 1 — GitHub
 `GitHub   ↓ README   ↓ Music Index   ↓ Track   ↓ Telegram   ↓ Listening ` 
### Path 2 — Telegram
 `Telegram   ↓ Track   ↓ Artist / Archive   ↓ GitHub   ↓ Music Index   ↓ Further Discovery ` 
### Path 3 — Spotify
 `Spotify   ↓ Playlist   ↓ Track   ↓ Radio Ainur   ↓ Telegram / GitHub ` 
These paths allow the same archive to be discovered from different user intentions.

## Social Sharing
 
When sharing Radio Ainur externally, the preferred destination should depend on the purpose of the message.
 
### For project introduction
 
Use the GitHub repository or GitHub Pages.
 
### For individual music discovery
 
Use the corresponding Telegram post.
 
### For continuous listening
 
Use the Spotify playlist.
 
This keeps each platform aligned with its strongest function.
  
## Promotion Principles
 
Radio Ainur promotion should follow the same editorial philosophy as the archive.
 
### Authenticity
 
Promotion should communicate what the project actually contains.
 
### Context
 
Whenever possible, explain what makes the collection or a particular track worth discovering.
 
### Consistency
 
Visual identity, terminology, and tone should remain consistent across platforms.
 
### Relevance
 
Promotion should target people interested in music discovery and curation rather than maximizing exposure indiscriminately.
 
### Sustainability
 
The promotion system should be maintainable without requiring constant high-volume publishing.
  
## Growth Model
 
The project can grow organically through the relationship between its platforms.
 `New Listener      ↓ Discovery      ↓ Track / Project      ↓ Platform Exploration      ↓ Archive Exploration      ↓ Repeat Listening      ↓ Long-term Audience ` 
The goal is to convert one-time discovery into continued exploration of the archive.
  
## Long-Term Discovery Strategy
 
As the archive grows, discovery should become easier rather than more difficult.
 
This requires maintaining:
 
 
- Accurate metadata
 
- Consistent indexing
 
- Stable links
 
- Clear documentation
 
- Searchable structure
 
- Cross-platform references
 
- A consistent visual and editorial identity
 

 
The archive should therefore be treated as an evolving discovery system rather than a static collection.
  
## Success Criteria
 
Promotion should ultimately be evaluated by the quality of discovery rather than exposure alone.
 
Useful indicators include:
 
 
- Repository visits
 
- Music Index visits
 
- GitHub Pages visits
 
- Telegram channel growth
 
- Individual post engagement
 
- Spotify playlist listeners
 
- Repeat interactions
 
- Cross-platform navigation
 

 
These indicators can help identify which discovery paths are most effective.
  
## Summary
 
Radio Ainur uses a connected ecosystem:
 `GitHub Structure + Documentation  GitHub Pages Discovery Interface  Telegram Publishing + Original Archive  Spotify Listening + Playlist Discovery ` 
Each platform has a distinct role.
 
Together they create a continuous path from discovery to listening, archiving, and revisiting.
 
**The objective is not simply to promote Radio Ainur, but to make the archive easier to discover, explore, and return to.**
